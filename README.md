# Master-Learn-Online-Learning-Platform-UI
Master Learn is a responsive online course platform inspired by Udemy, built using HTML5 and CSS3. The website provides a modern and user-friendly interface for learners to explore courses across multiple categories such as IT & Software, Business, Finance, Medical Coding, Personal Development, and Design.
